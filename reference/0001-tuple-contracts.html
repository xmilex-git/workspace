발표 직전 확인

공통 규칙=type_list · 현재 행과 탐색 위치=slot · 저장 대상=tuple bytes

  • NULL 비트맵: 0=NULL, 1=bound. NULL 없는 행은 생략.
  • 고정폭: 본문 크기 유지, 정렬 최대 4B.
  • DIRECT: 비정렬, 1/4B 헤더, index_*.
  • SCRATCH: 4B 정렬, 4B 헤더, data_*, 제자리 읽기.
  • locate=본문 포인터/길이/NULL. read_value=디코딩. NULL일 때 출력 값 미변경.
  • size→공간 확보→fill. prev_len은 페이지 writer.
  • 빠른 상수 오프셋은 첫 가변/첫 NULL 이전 구간. 이후 위치를 따라 탐색.
  • 70%는 (7,'abc') 튜플 예시. 파일/실행시간 보장 수치 아님.
