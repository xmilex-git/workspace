### Non-blocking (should consider)
2. `cbrd_24094.sh:43-44, 48-49, 155-158` (헤더 9, 12): "chain and its directory are torn down", "re-created after teardown"은 DELETE 시점에 성립하지 않음.
   - **코드**: DML DELETE는 `btree_mvcc_delete` -> `BTREE_OP_INSERT_MVCC_DELID`로 delete MVCCID만 표시한다(MVCC 논리 삭제). `btree_ovf_dir_remove_entry`/`btree_ovf_dir_destroy`는 물리 삭제 경로인 `btree_overflow_remove_object`(vacuum, insert undo)에서만 불린다.

   - **제안**: 삭제 단계 뒤에 tint처럼 `server stop -> vacuumdb -S -> server start`를 넣고, `show index capacity`의 키 수로 해체를 확인한다.
