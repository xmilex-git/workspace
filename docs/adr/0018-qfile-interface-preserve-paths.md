# Qfile 인터페이스 정리는 기존 자료구조와 최적화 경로를 유지한다

PR #7866의 이름과 호출 계약을 정리할 때 단일 튜플 레코드, PEEK/COPY 및 overflow 버퍼 재사용, 페이지 직접 작성과 기존 튜플 복사 경로를 유지한다. 사용자의 2026-09-08 합의이며, 타입 분리와 쓰기 경로 통합은 변경량·추가 복사 및 할당 위험에 비해 필요성이 입증되지 않아 기본 범위에서 제외한다.

일반 호출에서 레이아웃·인코딩을 숨긴다는 목표는 새로운 래퍼나 공통 버퍼를 추가한다는 뜻이 아니다. 의미 변경은 구체적인 오용 또는 계약 불일치와 비용 근거가 생긴 항목에 한해 별도로 결정한다. ADR 0016의 포맷·알고리즘 결정을 변경하지 않는다.

구체 심볼은 [기획](../plans/qfile-interface-refactor.md)에서 별도로 합의한다.

사용자 최종 범위 정정: PR이 새로 도입하거나 변경한 튜플 코드의 이름·의미 정리에 한정한다. 핵심은 SCRATCH 분류와 신규 qfile_type_list_finalize이며, PR 이전 리스트·스캔 함수와 기존 타입의 일괄 개명은 하지 않는다. 앞선 일곱 함수 일괄 제외 해석 중 신규 finalize 제외는 철회한다.
