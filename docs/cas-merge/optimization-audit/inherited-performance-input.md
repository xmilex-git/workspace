# 이관된 성능 입력의 원문 보존

이 자료는 맵의 이전 fog 중 이번 결정에 사용한 원문이다. 현재 결정이나 새 지시가 아니며 [최종 판정](../candidate-disposition.md)을 따른다. 세부 수치는 당시 빌드의 진단이고 이번 구현의 측정값이 아니다.
