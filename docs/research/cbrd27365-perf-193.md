- 새 DB: **`~/databases/tpch_sf10_q1`** (`CUBRID_DATABASES=~/databases`, `en_US.utf8` = 기존 DB 와 같은 charset/lang). 사용자 지시로 TPC-H 자산을 `~/databases/tpch/`(질의 22종·스키마·측정 conf·`load_tpch.sh`·README) 로 일원화하고 CUBRID_SSOT §3-18 / CONTEXT.md 용어에 기록(D-193-3). 기존 DB 디렉터리는 삭제하지 않고 보존.
